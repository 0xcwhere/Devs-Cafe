# ☕ Devs Cafe

> Your go-to spot for learning resources in Development, Cybersecurity, and AI.

## What is this?

Devs Cafe is a curated hub of **books, roadmaps, and resources** for anyone starting their journey in:

- 💻 **Software Development**
- 🔐 **Cybersecurity** (Pentesting, Bug Bounty, Blue/Red Team)
- 🤖 **Artificial Intelligence & Machine Learning**

Built by a learner, for learners — no fluff, just structured paths to help you go from zero to skilled.

## Why Devs Cafe?

Most people get lost in "where do I start?" — too many scattered resources, no clear order. This repo fixes that by organizing everything into clean roadmaps so you know exactly what to learn next.

## What's Inside

- 📖 Recommended books (organized by skill level: Beginner → Advanced)
- 🗺️ Step-by-step roadmaps for each track
- 🔗 Free/paid resource links (courses, labs, CTFs)
- 🛠️ Tools & practice platforms per topic
